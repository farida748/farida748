## 🚀 Featured Projects

### 🏋️ [Gym Management System](https://github.com/farida748/GymManagmentSystem)
ASP.NET Core MVC application for managing gym members, health records, and membership plans.

- **3-layer architecture** (Presentation / Business Logic / Data Access) in separate projects
- **Generic Repository** with async queries and no-tracking reads
- **9 entities** modeled with EF Core Fluent API: inheritance, owned types, composite keys, unique indexes, and check constraints
- Server-side validation with ViewModels, keeping entities out of the views

`ASP.NET Core MVC` `EF Core` `SQL Server` `LINQ` `Repository Pattern`

### 🤖 [PDF Chatbot](PDF_CHATBOT_REPO_LINK)
AI-powered web app that lets users upload a PDF and ask questions about its content.

- Integrated the **Gemini API** to generate answers grounded in the uploaded document
- Built with ASP.NET Core MVC

`ASP.NET Core MVC` `Gemini API` `Generative AI`
